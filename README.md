# Collider Event Display

Ebitengineで書いた、衝突型加速器の物理シミュレーター.
LHC の r-φ 断面図を模した表示の上で、

```
事象生成 → 検出器応答 → 再構成 → 不変質量ヒストグラム
```

を一貫して行う。Z / W / H の生成と崩壊を毎イベント生成し、ソレノイド磁場中の飛跡、
カロリメータのタワー、MET（消失横運動量）をその場で描画する.

## ビルドと実行

```
go mod tidy
go run .
```

Ebitengine v2.7 以降が必要（`vector.StrokeCircle` を使用）。動作確認は v2.9 系.

## 操作

| キー | 動作 |
|---|---|
| `1` – `6` | プロセス選択 (Zmumu / Zee / Zjets / Hgg / Wmunu / minbias) |
| `SPACE`, `R` | 新しい事象 |
| `F` | 500 事象を高速生成してヒストグラムに追加（描画なし） |
| `C` | ヒストグラムをクリア |
| `UP` / `DOWN` | ソレノイド磁場を 0.5 T 刻みで変更 |

## 画面の見方

左が r-φ 断面、右が数値パネルとヒストグラム。

- 同心円 — 内側からビームパイプ / 内部トラッカー / ソレノイド / 電磁カロリメータ (ECAL) /
  ハドロンカロリメータ (HCAL) / ミューオンスペクトロメータ
- 飛跡の色 — 赤 = ミューオン（全層を貫通）、水色 = 電磁 (e, γ)、緑 = ハドロン
  中性粒子はくすんだ色で描かれ、直線で飛ぶ
- タワー — 黄色が ECAL、橙が HCAL。72 個の φ ビンに落ちた ET の大きさが棒の長さ
- 白い矢印 — 再構成された MET.`5`（W→μν）ではニュートリノの方向を指す

## プロセス一覧

| キー | プロセス | ヒストグラムに詰まる量 |
|---|---|---|
| `1` | Z → μ⁺μ⁻ | m(l⁺l⁻) |
| `2` | Z → e⁺e⁻ | m(l⁺l⁻) |
| `3` | Z → qq̄ (2 jets) | m(jet1, jet2) |
| `4` | H → γγ | m(γγ) |
| `5` | W⁺ → μ⁺ν | mT(μ, MET) |
| `6` | minimum bias (soft QCD) | MET |

## 遊び方のヒント

- 磁場を下げると飛跡がまっすぐになる. `UP` / `DOWN` で B を変えると、曲率
  1/R = 0.3qB/pT がそのまま絵になる.B を上げると低 pT 粒子が内部トラッカー内で
  ループしてカロリメータに届かなくなり、タワーから消える.
- レプトンチャンネルとジェットチャンネルの差. `1`（Z→μμ）で `F` を数回押すと
  91 GeV に鋭いピークが立つが、`3`（Z→jets）では低質量側に長い裾を引く.
  実験でレプトン終状態が好まれる理由がそのまま出る.
- H→γγ の幅は分解能で決まる.自然幅 4 MeV に対し、観測される幅は約 1.5 GeV.
- W→μν の mT にジャコビアンピークが 80 GeV 直下に立つ.

## 精度について

方針は 物理の正確さ > 見た目 > パフォーマンス.ローレンツブースト、2体崩壊の運動学、
Breit-Wigner のサンプリング、磁場中の飛跡は厳密に実装してある.

一方で、ボゾンの pT・ラピディティ分布（PDF を畳み込んでいない）、フラグメンテーション、
シャワーの縦方向発達、ジェットアルゴリズムはトイモデルの近似で、
ジェット多重度やジェット質量は定量的には信用できない.
コード中では `【近似】` マーカーで宣言している.

厳密／近似の切り分け、期待される数値、ロードマップ、コードを変更するときの規約は
[CLAUDE.md](CLAUDE.md) にまとめてある。
